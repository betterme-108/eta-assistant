# 英语教学助手 English Teaching Assistant

**初中英语「批改 → 错因分析 → 讲评备课」一体化教学系统。** 老师上传课时作业 / 考试试卷照片，系统自动批改评分、收集错题，AI 将错题归入 36 类错因本体库，教师确认后一键生成讲评方案与配套练习。学生零参与、零感知。

```
作业/试卷照片 ──► 自动批改评分 ──► 错题收集 ──► AI 归因（36 类）──► 教师确认/改判
      │                                                                │
      ▼                                                                ▼
成绩单（按学生查看 · 导出）                              讲评方案 · 配套练习 · 智能组卷
```

## 核心特性

- **自动批改**：听写与客观题本机规则判卷（快、稳、零 AI 成本）；主观题 AI 判定；作文分维评分（内容 / 语言 / 结构 / 书写）。AI 失败置「待判定」由教师把关，不静默给分。
- **拍照解析**：MinerU 主通道 OCR（备用 PaddleOCR / 通义 VL / 豆包视觉），自动读取姓名并关联学生名册。
- **36 类错因本体库**：A 词汇 / B 语法 / C 语篇 / D 表达 / E 行为五大组，「粗心 vs 未掌握」用结构化规则判别，不靠感觉。
- **教师主导**：AI 归因仅供参考，教师改判优先且全程留痕，统计口径在 SQL 层强制生效。
- **讲评方案**：讲什么、不讲什么、谁需面批由确定性算法产出，AI 只生成执行策略——数字可追溯，不评价学生。
- **学生错题档案**：按月趋势（错题数 + 五大错因组分布 + 环比变化），支持单生报告导出（打印友好，可另存 PDF）与全班报告打包下载。
- **配套练习 / 智能组卷**：可按时间范围生成；练习自动把班级真实错例注入 AI 提示词，贴合班级实际。
- **长列表分页**：错题确认、练习与试卷列表分页 + 滑块快速翻页，数据再多不卡顿。
- **隐私与反标签化**：学生全程代号，姓名永不进入模型请求；所有导出只呈现错题与计数，不排名、不生成评价性结论。

## 快速开始

```bash
# 方式一：一键脚本（自动建虚拟环境、装依赖、自检、启动并打开浏览器）
./start.sh            # macOS / Linux（macOS 也可双击 start.command）
start.bat             # Windows

# 方式二：手动三步
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。想立即看到完整效果：

```bash
.venv/bin/python scripts/seed_full.py --reset   # 2 班 / 20 人 / 456 条错题（一学年分层数据）
.venv/bin/python scripts/seed_demo.py --reset   # 轻量版：单班 10 人约 84 条
```

配置 AI：复制 `.env.example` 为 `.env`，填入 DeepSeek API key（模型走 OpenAI 兼容直连）与 MinerU token，重启生效。key 未配置时对应功能显式报错，不静默降级。

运行日志写入本机 `runtime/logs/`（按天轮转、保留 14 天）。
