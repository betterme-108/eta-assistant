# 英语教学助手 · 使用手册

> 面向初中英语教师。学生零参与、零感知——您拍照上传学生作业 / 试卷，系统自动分辨题目与学生作答并批改评分、把错题收集起来，AI 分析错因，您确认，它生成讲评方案。

## 一、它解决什么问题

英语教学助手把日常工作串成一条流水线：**批改（作业 / 试卷拍照上传、AI 解析自动批改评分）→ 收集错题 → AI 分析归入 36 类常见错因 → 您确认 → 生成讲评方案**。批改后您面对的不是"哪道题错了"，而是"为什么全班总在同一类地方摔倒"——传统做法靠经验回忆，讲评课容易变成"从第一题讲到最后一题"，本系统把这件事变成四步可复现的流程，并把"讲什么"的取舍交给透明规则而不是感觉。

## 二、四步操作

### 第 1 步：拍照批改作业 / 试卷（每次布置后，约 5 分钟）

批改前先在电脑上把照片按下面的结构整理好（一次约定，之后每批照做）：

```
批次文件夹：  班级-批改类型-唯一标识     例：九年级5班-考试试卷-半期考试
学生文件夹：  学生姓名                   例：林一诺
照片文件：    该生本次的照片             多张 = 多页，按文件名顺序排页
```

- **批改类型只有两个值**：`课时作业`、`考试试卷`（分别对应两个批改页，系统会按它把历史归到对应页）；
- **唯一标识**定位每一次提交，如 `1单元2课时`、`第一次月考`、`半期考试`；
- 命名不合规时系统会明确提示怎么改（如 `九年级5班-半期考试` → 建议 `九年级5班-考试试卷-半期考试`）。

- **📁 上传文件夹**：在「课时作业批改」或「考试试卷批改」页选择整个批次文件夹（或把文件夹拖进去）。系统立即核对命名并按学生分组预览——可移除整名学生或单张照片；班级与唯一标识自动带出（可修改，批改后也能点「✎ 修改信息」更正）。点「识别并解析」——AI 读取每名学生的照片（多张自动合并跨页大题）：按题号切出题目（题干 / 题型 / 选项 / 原文）、认出学生手写的作答并给出参考答案（每张约 30–120 秒）；姓名优先取学生文件夹名（比照片识别更可靠）并与名册匹配。无需手抄题目与作答。
- **📝 提取原文可直接编辑**：解析后可直接改原文（识别错字、漏题），点「✓ 应用修改并重新解析」后题目与作答按修改刷新。
- **🔤 印刷与学生笔迹严格区分**：填空题印刷体已给的部分（字母前缀如 `incom___`、括号提示词如 `(great)`、空线前后的印刷文字）属于题干，只有学生手写补写的字母 / 单词才是作答——AI 解析按此规则执行，核对时留意这一区分即可。
- **✅ 逐题核对**：解析完成后逐题核对——题型 / 题干 / 参考答案 / 分值均可修改，学生可重选、作答可修正；同一名学生的多张照片按题号自动合并，不同学生共用一套题，每题标注来源照片。**AI 给的只是建议，以您核对的为准。**
- **🚀 开始批改**：选择 / 判断等客观题用规则比对（秒出结果、不花 AI 费用）；完成句子 / 概要补全 / 任务型阅读等主观题由 AI 判定对错（参考答案可留空）；**书面表达（作文）由 AI 按四个维度评分**（内容要点 / 语言准确性 / 结构连贯 / 书写规范，附分维评语）。判错的题自动进入错题库待确认；AI 拿不准的题标"待判定"由您把关——不计分、不自动入库。
- **📥 结果按学生查看与导出**：批改结果页顶部有学生下拉框，页面每次只显示一名学生（切换逐生查看，互不干扰）；导出三种口径——「导出全班结果」下载整班汇总 CSV（每生一行：得分 / 正确数 / 错题数与 AI 总结建议），学生卡上的「⇩ 单生报告」下载该生打印友好网页（逐题明细 + AI 总结与建议，可另存 PDF），「⬇ 全部单生报告」把每生的独立报告各一个文件打包成一个 zip 一次下载，免逐生点击（AI 总结逐生生成，学生多时需稍等）。
- **➡️ 批改完成后闭环不断链**：右栏五步引导（上传 → 识别解析 → 逐题核对 → 开始批改 → 查看报告）随进度逐步点亮，批改出报告后第 5 步亮起，点报告卡里的「去错题确认 →」直达确认页——判错的题已自动入库待确认，看完报告顺手确认，流程一气呵成。

> 注意：**听力等音频类题目不在本系统范围**（系统不做语音识别与合成）。书面表达（作文）支持分维评分，不涉及朗读 / 口语打分。

### 第 2 步：录入错题（补充手改错题，约 10 分钟）

批改中判错的题已自动进入「错题确认」页待确认，无需重复录入；此页用于补充平时手改的错题。

1. 打开系统，**右上角先选定班级**（多班同教时全局切换，所有页面联动；班级旁边的「＋」可随时新建班级）。
2. 进入「错题录入」页，两种方式任选：
   - **📷 拍照切题（推荐）**：一次上传 1–10 张照片（试卷页、书本页、多页连拍均可）——AI 自动切出每一道题并识别题型（选择/判断/完形/阅读混排也能分），跨页题自动合并；逐题核对后一次提交全部分析。识别不佳时，也可让学生自行裁剪单题照片发来，用「单题录入」上传；
   - **✎ 单题录入**：手动输入题干与学生作答（或上传学生裁剪好的单题照片，题干留空自动识别）；关联学生时输入代号或姓名实时搜索（↑↓ 选择、Enter 确认），Ctrl+Enter 快速分析。
3. 点击开始后——AI 依据 36 类常见错因给出分析建议、判断依据与教学要点。
4. **必须由您确认**：到「错题确认」页采纳 / 改判 / 忽略。只有确认后的数据才进入统计。**减负技巧**：AI 有把握的（≥80%）一键批量采纳，其余逐条把关——确认从逐题点击降为抽检；页顶「批次」下拉可先锁定某次作业 / 考试再批量确认，其余批次不受影响。错题多时列表自动分页（每页 50 条），拖动滑块或点上/下页快速翻看，页面不会卡顿。

录入量建议：一次批改的典型错题 20~40 条，不必录入每一道错题——录的是"值得讲的典型错例"，不是错题全集。

**班级、名单、任务类型、唯一标识从哪里来？——都是使用时随手建，无需提前准备：**

- **班级**：右上角「＋」新建（空班级也可先建）；学生管理页每个班级旁有「✎ 管理」可改名；删除班级会连带删除该班全部数据（学生 / 错题 / 配套练习 / 组卷 / 批改记录），操作前有二次确认提示；
- **名单**：学生管理页逐人添加或批量导入（导入行里写班级即可，没写班级的行自动归入右上角当前班级）；点任一学生可看其个人错题档案（含📈按月错题趋势与环比变化，仅供您辅导参考）——可单独导出该生报告（打印友好网页，可另存 PDF），也可「⤓ 全班学生报告」打包 zip 一次下载（报告只呈现错题与计数，不评价、不排名）；
- **任务类型**：课时作业 / 考试试卷两种，录入时直接选择即可；**唯一标识**定位每一次提交（如 `1单元2课时`、`半期考试`），用过的标识会进入候选列表，新标识输入一次后同样会被记住。

### 第 3 步：错因分析（总览 / 趋势两段，随时看）

「错因分析」页内分两段，页顶共用一个「批次」下拉（全部批次 / 某次作业 / 某次考试）——想回答“这次考得怎么样”而不只是全期平均，选定批次即可，总览与趋势随之过滤：

- **总览**：顶部**小结**一句话概括本班现状（已确认多少题、错因集中在哪、什么在上升）；下方四张卡（错题总数 / 待确认错因 / 已确认计入统计 / 涉及学生人数）、**主要错因**排行、**周错题量**分周走势与**预警**（比上一周增加超 50% 且 ≥3 人次时提醒），可一键导出错题明细表格。
- **趋势**：按周 / 月 / 半年三种时间粒度看错因走势，另有**题型趋势**（前 6 种题型错得多不多、是否在下降）与**需关注学生**（错题最多的前 8 人及主要错因，点击看个人档案）；顶部两张卡展示**您的改判率**与**您改判的题数**——讲评有没有效果，曲线说话。

### 第 4 步：讲评备课——生成讲评方案（备课时）

1. 进入「讲评备课」→「讲评方案」标签，选择班级与任务类型；**数据范围**支持三种：**全部历史**（默认，看全貌）/ **按批次**（多选某几次作业或考试，如只讲评这次期中）/ **按阶段**（时间范围，如上学期、开学以来），选定后点「生成」。
2. 得到四段式讲评方案：
   - **① 本课重点讲**：错得最多的前 3 类（≥3 人次才入围），附人次、典型错例、教学要点；
   - **② 本课不讲清单**：错误率低于 10% 的错因——个别反馈解决，不占课堂时间；
   - **③ 个别辅导名单**：同类错因 ≥4 次的学生（仅代号），附面批建议；
   - **④ AI 讲评执行策略**（可选，点「✦ AI 讲评策略」按需生成）：总体策略与 45 分钟时间分配、每类重点错因的切入话术/讲解步骤/板书建议——AI 只负责“怎么讲”，名单与数字仍来自透明规则。
3. 可直接打印（页面右上「打印」按钮），生成后自动留档快照。

## 三、配套练习与智能组卷（讲评后巩固）

**配套练习**：「讲评备课」→「配套练习」标签（或讲评方案“去生成→”一键跳转并自动预选类别）为重点错因生成针对性练习；生成卡上可设「错例时间范围」（起止日期或近一月 / 近三月 / 近一年快捷）——AI 会参考该阶段班级的真实错例出题，更贴合班级实际，范围随练习留档显示在卡片上（留空 = 全部历史）。**AI 生成的练习一律标记“AI 生成·待审校”，您逐题审校通过后才会附入讲评方案**（对应《教师生成式AI应用指引》“加强内容审查把关”要求）。练习多时列表分页展示（每页 10 套，滑块翻页）。

**智能组卷**：「讲评备课」→「智能组卷」标签基于本班已确认错题分布生成综合试卷（题量与难度可调，也可自动适配，含选择题 / 阅读 / 书面表达混合题型），生成前同样可设错题时间范围——只统计该阶段内确认的错题（留空 = 全部历史；阶段内没有确认错题时会提示先去确认）；生成后同样先审校——教师版可随时导出核对，学生卷只能导出已审校通过的试卷。试卷列表分页展示（每页 10 套，滑块翻页）。

## 四、三条使用禁令（重要）

1. **不得下发排名**：讲评方案、练习、辅导名单不得以任何形式发给学生或家长进行比对排名。
2. **不得用于学生评价**：错因数据不得进入学生综合素质评价、评优评先等任何评价场景。个别辅导名单是给您的教学提示，不是给学生贴的标签。
3. **代号与姓名的对应关系只存在您这台电脑上**：只保存在您这台电脑上，不出现在任何导出文件、打印页与 AI 请求里。

## 五、常见问题

**Q：AI 归错了怎么办？**
A：在「错题确认」页选正确类别后点「改判确认」。系统统计一律以您的改判为准，且改判会留下记录，形成“您的改判率”——这正是系统“AI 辅助、您主导”的证据。

**Q：学生需要安装或注册吗？**
A：完全不需要。学生零参与、零感知是本系统的设计原则。

**Q：数据在哪里？**
A：全部在您这台电脑上的数据文件（`runtime/db/eta.db`）里，不联网上传、不注册账号。定期备份该文件即可。

**Q：遇到问题（识别失败、页面报错）怎么排查？**
A：系统会自动记录运行日志，保存在您电脑上的 `runtime/logs/` 文件夹（按天保存、保留 14 天自动清理；同一天多次重启会追加到同一个文件，每次启动/停止都有分隔线标记）；页面出问题时也会直接弹出错误提示，详情已同步记入日志，可将日志文件发给技术人员排查。终端窗口只显示关键事件（启动/停止、AI 调用、报错），不会被刷屏。

**Q：一张照片里有多道题、题型也不一样，能拍吗？**
A：可以——用「📷 拍照切题」模式，整页拍或多页连拍，AI 自动切题并识别题型，您勾选核对后一次提交。识别不准的题可在卡片里直接编辑修正。

**Q：一个人录全班错题，工作量会不会太大？**
A：三个减负设计：① 只录"值得讲的典型错题"，拍照切题时同一题可关联多个学生一次录入；② 拍照切题一次录整页；③ 错题确认页 AI 有把握的一键批量采纳。也可让学生自行裁剪单题照片发来，您逐张上传即可。另外，批改页判错的题会自动入库，这部分不用再录。

**Q：批改结果能导出吗？**
A：能，三种口径：①「导出全班结果」——整班汇总 CSV（Excel 直接打开，每生一行：得分、正确数、错题数与 AI 总结建议）；②「⇩ 单生报告」——学生卡上的链接，下载该生的打印友好网页（逐题明细 + AI 总结与学习建议，可另存 PDF 发给家长）；③「⬇ 全部单生报告」——每生的独立报告各一个文件，打包成一个 zip 一次下载。结果页顶部学生下拉框切换逐生查看。课时作业批改与考试试卷批改都支持。

**Q：听力题能批改吗？**
A：不能。本系统不做语音识别与合成（ASR / TTS），听力、朗读、口语等音频类题目不在系统范围——批改时请只选文本类题型；书面表达（作文）支持 AI 分维评分。
