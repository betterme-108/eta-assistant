# 英语教学助手 · 安装手册

> 目标：任何一位有普通电脑的教师，10 分钟内在这台电脑上跑起来。需要先配置 DeepSeek key（主观题判定、作文分维评分、错因归因与练习生成）与 MinerU token（拍照识别），其余全部本地运行。客观题规则判卷为纯本地（零 AI 成本），无需任何 AI 配置。

## 一、环境要求

- 联网（仅首次运行需要：自动安装 Python 并下载依赖；之后可完全离线运行）
- 浏览器（Chrome / Edge / Safari 均可）
- **无需预装 Python**：一键脚本会自动检测并安装——macOS / Linux 的 `start.sh` 自动探测（无则用 Homebrew 或 apt 安装），Windows 的 `start.bat` 自动通过 winget 安装 Python 3.12
- 不需要数据库软件、不需要注册任何账号

### 依赖安装到哪里？（不污染系统）

一键脚本对安装位置有明确分工：

| 安装内容 | 安装位置 | 说明 |
| --- | --- | --- |
| 项目依赖（FastAPI / uvicorn / PyYAML 等） | **项目目录内的独立虚拟环境 `.venv/`** | 不写入系统 Python 路径；卸载本系统 = 删除整个项目目录即可 |
| Python 运行时 | 仅当电脑上没有 Python 时才安装：macOS 用 Homebrew（用户级，无需 sudo）、Windows 用 winget（装到当前用户目录 `%LOCALAPPDATA%`）、Linux 用 apt | 这是唯一可能装在项目外的部分——运行必需的基础环境 |

> 简单说：**依赖不进系统路径，全部装在项目自己的 `.venv/` 里；只有电脑缺 Python 时才会装一份 Python 运行时。** 脚本运行时会明确打印这一信息。

## 二、安装步骤（一键脚本，推荐）

**macOS / Linux**

```bash
cd eta-assistant
./start.sh    # 首次运行自动：装 Python（如缺）→ 建虚拟环境 → 装依赖 → 自检 → 启动
# 国内网络依赖下载慢可加镜像：PIP_MIRROR=1 ./start.sh
```

**Windows**

双击 `start.bat`，首次运行自动完成：winget 安装 Python 3.12 → 建虚拟环境 → 装依赖 → 启动。

> 无 Python 时的自动安装策略：macOS 优先用 Homebrew 装 python@3.12（无 Homebrew 则提示官网下载）；Linux 用 `sudo apt-get` 装 python3/python3-venv/python3-pip；Windows 用 `winget`（老系统无 winget 则提示 python.org 下载）。装好后重新运行同一脚本即可继续。

手动方式（可选，环境已就绪时）：

```bash
# 1. 进入项目目录
cd eta-assistant

# 2. 创建虚拟环境（Windows 用 python -m venv .venv）
python3 -m venv .venv

# 3. 安装依赖（仅 5 个包，无重型依赖）
.venv/bin/pip install -r requirements.txt
#    Windows: .venv\Scripts\pip install -r requirements.txt
#    国内网络慢可加镜像：-i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 运行测试（可选，确认环境完好，应显示全部通过）
.venv/bin/python -m pytest tests/ -q
```

## 三、配置 AI 并启动

### 1. 填入 API key

复制 `.env.example` 为 `.env`，填入：

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxx        # DeepSeek 平台申请（归因与练习生成）
LLM_MODEL=deepseek-v4-pro           # 默认即此，可不填
# 拍照识别（推荐）：MinerU token
OCR_PROVIDER=mineru
MINERU_TOKEN=xxxxxxxx               # https://mineru.net/apiManage/token 申请（14 天有效）
# 或：OCR_PROVIDER=paddleocr + PADDLEOCR_TOKEN=xxxxxxxx
```

> 系统为真实 AI 单模式：key 未配置时对应功能在页面显式报错（不降级、不静默），避免给出不可信结果。

### 2. 启动

**方式一：一键脚本（推荐）**

```bash
双击 start.command   # macOS：双击即启动（关闭终端窗口即停止服务）
./start.sh           # macOS / Linux：终端运行，自动创建虚拟环境并装依赖（首次）、
                     # 检查 .env、快速自检、清理旧进程、启动、就绪后自动打开浏览器
start.bat            # Windows：双击或命令行运行，效果同上
```

> macOS 首次双击 `start.command` 若被系统拦截（文件经由网盘/微信传输时会有安全标记），右键该文件 →「打开」一次即可，之后双击正常。

端口默认 8000，可用 `PORT=9000 ./start.sh` 自定义；重复执行会先停掉旧服务再启动。脚本要求 `.env` 已存在（未配置时会提示需要填写的 key 后退出）。

**方式二：手动启动**

```bash
.venv/bin/uvicorn app.main:app --port 8000
# Windows (PowerShell): .venv\Scripts\uvicorn app.main:app --port 8000
```

浏览器打开 <http://127.0.0.1:8000>，看到「英语教学助手」界面即成功。

一键灌入演示数据（推荐全量版：9年级20班 + 9年级21班 · 每班 10 名学生 · 一学年 13 批次（8 次课时作业 + 5 次考试，2025-09 → 2026-06）· 456 条错题，能力分层/班级画像/叙事曲线/改判留痕俱全，错因分析（总览/趋势，含按批次筛选）与讲评备课讲评方案（含批次/阶段范围）立即可见）：

```bash
.venv/bin/python scripts/seed_full.py --reset
# 轻量版（可选）：.venv/bin/python scripts/seed_demo.py --reset   # 单班 10 人约 84 条
```

> 演示数据由脚本确定性生成（固定随机种子，任何人复现得到同一份数据），**不调用任何大模型接口**，仅用于功能演示与评委复现。真实使用时的数据由教师日常批改自动积累。

启动后归因与练习生成走 DeepSeek（OpenAI 兼容直连），OCR 默认走 MinerU（文档解析，含链路抖动自动重试）；备选 `paddleocr`（星河社区异步 jobs）或 `dashscope` / `doubao`（通义 VL / 豆包视觉）。

> 安全提示：`.env` 只在您这台电脑上，不要提交到代码仓库。系统发往大模型的内容**只有题目文本**，不含学生姓名与代号。

## 四、他人复现路径（比赛配套资源）

评委/同事拿到代码包后：

1. 解压 → 在项目目录执行 `./start.sh`（Windows 双击 `start.bat`）——首次运行自动装 Python（如缺）并创建虚拟环境、安装依赖；尚未配置 `.env` 时脚本会提示需要填写的 key
2. 按「三、配置 AI 并启动」填入 `.env`（DeepSeek key + MinerU token），再次执行 `./start.sh` 即启动并自动打开浏览器
3. `.venv/bin/python scripts/seed_full.py --reset`（可选，看双班完整演示数据）
4. 除 AI 通道外全部本地运行，无需注册任何账号。

## 六、常见问题

**Q：AI 调用失败会怎样？**
A：归因失败不阻断录入——该条自动置为"待确认"由教师判断；练习生成失败则在页面显式报错提示重试。key 未配置时对应功能直接报错（系统为真实 AI 单模式，无演示降级）。

**Q：端口被占用？**
A：换一个，如 `--port 8001`。

**Q：依赖都安装到哪里了？会不会弄乱我的电脑？**
A：不会。项目依赖（FastAPI/uvicorn 等）全部装在项目目录内的独立虚拟环境 `.venv/`，不写入系统路径——想卸载就把整个项目目录删掉；唯一例外是电脑上没有 Python 时，脚本会安装一份 Python 运行时（macOS 装到 Homebrew、Windows 装到当前用户目录，均非系统目录）。启动时终端里会明确提示安装位置。

**Q：数据怎么备份/迁移？**
A：复制 `runtime/db/eta.db` 单个文件即可。

**Q：听写、作业批改需要额外的配置吗？**
A：不需要——客观题（含听写题型）用规则判卷，完全本地运行、零 AI 成本；主观题判定、作文分维评分、AI 总结建议与错因归因共用同一个 DeepSeek key。听力等音频类题目不在系统范围，无需语音服务。
