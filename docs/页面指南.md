## 一、系统的核心能力是什么

**一句话：教师拍照上传学生作业 / 试卷 → AI 自动分辨题目内容与学生作答并批改评分、把错题收集进库 → AI 把每道错题分析到 36 类常见错因 → 教师确认 → 系统自动生成讲评方案（讲什么、不讲什么、谁需要面批），并配套生成针对性练习与综合试卷。**

它不是"又一道错题本"，也不是单纯的批改工具。错题本回答"哪道题错了"；批改工具只回答"对错与得分"；英语教学助手回答"**为什么全班总在同一类地方摔倒，以及下节讲评课该怎么办**"。核心能力拆开是五件事：

| 核心能力 | 做什么 | 关键设计 |
|---|---|---|
| ① 拍照批改 | 选择批次文件夹上传学生作业 / 试卷照片 → AI 解析题目与作答、给出参考答案 → 核对后自动批改评分，判错的题直接进错题库 | 智能体会话主路解析（每张约 30–120 秒）；客观题规则判卷（归一化比对 + 拼写容错，零 AI 成本）；完成句子 / 概要补全 / 任务型阅读 AI 判定对错；书面表达（作文）AI 按内容要点 / 语言准确性 / 结构连贯 / 书写规范四维评分；AI 拿不准置"待判定"由您把关——不计分、不静默入库；听力等音频类题目不在范围 |
| ② 拍照解析 | 学生作业 / 试卷照片 → 自动读出姓名、切出题目、认出学生手写作答 | 智能体提取原文可直接编辑，修改后重新解析（识别错字、漏题直接改原文）；姓名优先取学生文件夹名并与名册匹配，匹配不上可手动选择；识别结果逐题可核对，AI 给的只是建议 |
| ③ 错因分析 | 每道错题 → 36 类错因之一（不是记题目，是记"为什么错"） | 36 类清单约束（AI 只能从 36 类里选并给出证据）；E 类"粗心 vs 未掌握"用历史频次+班级基准的结构化规则判别，不靠感觉 |
| ④ 讲评方案 | 班级错因分布 → 可打印带进教室的讲评方案 | **规则出数据 + AI 出策略的混合架构**：重点讲错得最多的前 3 类（≥3 人次）、不讲清单（<10%）、个别辅导（同类≥4 次）由确定性算法产出，数字可追溯；AI 讲评执行策略（切入话术/步骤/板书）由大模型基于这些数据生成，硬性约束"数字以给定数据为准、不评价学生"，您把关 |
| ⑤ 配套练习与智能组卷 | 讲评后巩固：AI 按错因生成练习、按错题分布组卷，均可按时间范围（阶段）生成 | 练习与试卷一律为草稿状态（AI 生成·待审校），您逐题通过后才可附入讲评方案或导出学生卷——审校环节不可绕过；练习生成时把阶段内班级真实错例注入 AI 提示词（更贴合班级实际） |

**两条底线（系统的伦理设计）：**

- **教师主导**：AI 分析只是草稿，一切统计只认教师确认后的口径；教师改判优先写进 SQL（`COALESCE(teacher_override, category_id)`），全程留痕并形成"您的改判率"指标。
- **学生零参与、反标签化**：学生全程无感知；系统一切页面只显示学生代号；不存在任何"按学生输出评价/排名"的端点；发往大模型的内容只有题目文本，不含学生标识。

## 二、错题包括哪些题

### 来源与录入方式

错题来自**批改自动收集**与**教师手动录入**两个渠道，全部由教师（不是学生）操作：

**渠道一 · 批改自动收集（推荐）**：「课时作业批改」「考试试卷批改」两页批改时，判错的题自动进入「错题确认」页待确认——选择 / 填空错题、主观题失分、作文得分未满，都会带上题干、学生作答与正确答案入库，只等您确认。

**渠道二 · 手动录入**：在「错题录入」页补充平时手改的错题，两种方式：

1. **拍照切题（主入口）**：一张照片多道题一次录入，AI 自动切题、认出学生作答并分析；
2. **单题录入**：手动输入题干 + 学生作答（错例）+ 正确答案；题干留空时上传照片，自动识别题目文字。

每条错题挂三个教学维度：**任务类型**（课时作业 / 考试试卷）、**唯一标识**（如 `1单元2课时`、`半期考试`，定位每一次提交）、**学生代号**（选填，用于 E 类行为复核与个别辅导名单）。

### 题型覆盖

单选、多选、判断题、语法选择、完形填空、阅读理解、口语应用、任务型阅读、完成句子、概要补全、书面表达、词语运用、听写、其他——覆盖初中英语作业与试卷的全部主流**文本类**题型（**听力理解等音频类题目不在范围**：系统不做语音识别与合成）。题型是录入与批改时的辅助信息，**分析与统计按"错因类别"而非按题型组织**（同一错因如"时态误用"可出现在单选、完形、写作多种题型中）。

### 错因覆盖：36 类常见错因（系统核心资产）

| 组 | 类数 | 类别 |
|---|---|---|
| A 词汇知识 | 6 | A01 拼写与形近词 · A02 词形变化 · A03 词义辨析 · A04 固定搭配与短语 · A05 冠词与限定词 · A06 代词与指代 |
| B 语法结构 | 9 | B01 时态误用 · B02 被动语态 · B03 情态动词 · B04 非谓语动词 · B05 从句与连接词 · B06 主谓一致与 there be · B07 比较等级 · B08 句子成分与语序 · B09 词性误用 |
| C 语篇理解 | 8 | C01 主旨大意误判 · C02 细节定位错误 · C03 推理判断越界 · C04 词义猜测无依据 · C05 作者态度/意图误读 · C06 篇章结构与指代 · C07 完形语境线索缺失 · C08 信息转述与整合 |
| D 书面表达 | 8 | D01 内容要点缺失 · D02 文体与格式错误 · D03 人称与时态不符 · D04 中式英语表达 · D05 衔接与连贯缺失 · D06 语用不得体 · D07 字数不足或超限 · D08 卷面与书写规范 |
| E 答题行为 | 5 | E01 审题偏差 · E02 粗心性失误 · E03 检查缺失 · E04 空白未答 · E05 知识未掌握 |

其中 C 组（语篇理解，含完形与信息转述）是市面工具的普遍空白区；E 组用结构化规则区分"粗心（E02）vs 未掌握（E05）"——这是"错题本"类产品做不到的。

### 不收录什么

整卷原题存档、正确题目、与英语学习无关的行为记录。系统只关心"错例 + 错因分析"，一条错题的完整字段是：题干、学生作答、正确答案、题型、任务类型、唯一标识、学生代号、AI 分析类别与证据、教师确认结果。

## 三、导航与顶栏（全局功能）

导航标签按日常工作流分四组：**作业批改**（课时作业批改 / 考试试卷批改）→ **错题管理**（错题录入 / 错题确认 / 错因分析）→ **讲评备课**（讲评方案 / 配套练习 / 智能组卷）→ **学生管理**——标签顺序就是“批改 → 收集确认 → 分析讲评”的工作顺序。「错因分析」页内分两段（总览/趋势，详见后文）；升级前的旧页面地址会自动跳转到新页并定位对应分段。

| 元素 | 作用 |
|---|---|
| 品牌「英语教学助手 English Teaching Assistant」 | — |
| **班级选择器**（顶栏右侧） | 全局筛选：切换后**所有页面**（错题录入 / 错题确认 / 错因分析 / 讲评备课 / 学生管理）都只显示该班数据；「全部班级」聚合视图；旁边的「＋」随时新建班级（无需预先建好） |
| 深色模式按钮 | 手动切换深/浅色；首次访问跟随系统设置，选择记忆在这台电脑上 |

## 四、七个页面逐一说明（按导航分组顺序）

### 1. 课时作业批改——批次文件夹上传，AI 解析题目与作答（默认首页）

**功能**：把整批学生作业照片按约定结构放好，选择批次文件夹上传——AI 读取每名学生的照片（多张自动合并跨页大题），按题号切出题目（题干 / 题型 / 选项 / 原文）、认出学生手写的作答并给出参考答案，您核对修正后一键批改；判错的题自动进入错题库待确认。无需手抄题目与作答。

**批次文件夹结构（一次约定，之后每批照做）**：

```
批次文件夹：  班级-批改类型-唯一标识     例：九年级5班-课时作业-1单元2课时
学生文件夹：  学生姓名                   例：林一诺
照片文件：    该生本次的照片             多张 = 多页，按文件名顺序排页
```

批改类型只有两个值：`课时作业`、`考试试卷`；唯一标识定位每一次提交（如 `1单元2课时`、`第一次月考`、`半期考试`）。也可用**两段式**「班级-唯一标识」命名——此时批改类型以当前页面为准。命名不合规时系统会明确提示怎么改（如 `九年级5班-半期考试` → 建议 `九年级5班-考试试卷-半期考试`）。

**界面**：上方**本次批改信息卡**（班级 / 唯一标识——选好文件夹自动带出，批改后也可随时修改；批改类型与单元由文件夹命名自动留档，不在界面展示）；左卡选择批次文件夹 → 系统立即核对命名并按学生分组预览（可移除整名学生或单张照片）→ 点「识别并解析」；解析完成后下方展开「📄 解析结果 · 提取原文」与「⚙️ 核对修正」两区。**适合每天的课时作业与课后练习；听力等音频类题目暂不支持。**

**操作**：

1. 按约定结构整理照片 → 选择批次文件夹（或把文件夹拖进去），系统核对命名并按学生分组预览；
2. 核对分组：班级与唯一标识自动带出（可改），移除不需要的学生或照片后点「识别并解析」（每张约 30–120 秒）；
3. **智能体提取原文可直接编辑**：识别错字、漏题可直接在原文里改，点「✓ 应用修改并重新解析」后题目与作答按修改刷新（复用同一套解析规则）；
4. 展开「核对修正」区逐题核对——题型 / 题干 / 参考答案 / 分值均可修改，学生可重选、作答可修正；同一名学生的多张照片按题号自动合并，不同学生共用一套题。**AI 给的只是建议，以您核对的为准。**
5. 点「开始批改」：
   - **客观题**（单选 / 判断 / 语法选择 / 完形填空 / 阅读理解 / 词语运用等）：归一化比对参考答案，规则判卷（零 AI 成本）；
   - **短主观题**（完成句子 / 概要补全 / 任务型阅读）：AI 对照参考答案判定对错并给出理由，参考答案可留空；
   - **书面表达（作文）**：AI 按**内容要点 / 语言准确性 / 结构连贯 / 书写规范**四个维度打分，得分未满即作为失分错题收集，分维评语附在结果卡里；
   - AI 拿不准或调用失败 → 该题标"待判定"：**不计分、不自动入库**，由您当场把关（不静默给分）；
6. 结果页顶部**学生下拉框**逐生切换查看（页面每次只显示一名学生，选项带学号 / 姓名 / 得分），学生卡内看得分与逐题判定（绿=对 / 橙=拼写小错 / 红=错 / 灰=待判定 / 白=未写），作文卡附分维评语；导出三种口径——「导出全班结果」整班汇总 CSV（每生一行：得分 / 正确数 / 错题数与 AI 总结建议）、学生卡上「⇩ 单生报告」该生打印友好网页（逐题明细 + AI 总结与建议，可另存 PDF）、「⬇ 全部单生报告」每生一个独立文件打包 zip 一次下载。**右栏五步引导**（①上传 → ②识别解析 → ③逐题核对 → ④开始批改 → ⑤查看报告）随进度逐步点亮，批改出报告后第 ⑤ 步变绿，点报告卡里的「去错题确认 →」直达确认页——判错的题已自动入库，流程不断链。

**背后逻辑**：批改即收集——判错的题直接按"题干 + 学生作答 + 正确答案 + 题型"写入错题库待确认，与手动录入共用同一套 36 类分析与确认流程；客观题规则判卷零 AI 成本；解析提示词硬性约束**印刷已给与学生补写严格区分**（填空题印刷的字母前缀如 `incom___`、括号提示词如 `(great)` 属题干，只有学生手写补上的字母 / 单词才是作答），避免把题干当成错因证据；**反标签化**：识别出的姓名只用于本机名册匹配，发往 AI 的内容只有题目文本与作答（或作业照片本身），不含学生姓名与代号。本页与「考试试卷批改」共用同一条批改链路，仅场景预设不同。

### 2. 考试试卷批改——单元测试 / 月考 / 期中期末整卷批改

**功能**：与「课时作业批改」同一套拍照批改引擎，预设为考试场景——适用于单元测试、月考、期中测试、期末测试等**整卷批改**。

**界面与操作**：与课时作业批改完全一致（批次文件夹上传 / 分组预览 / 识别解析 / 原文编辑重解析 / 逐题核对 / 批改 / 学生下拉切换与三种导出），差异有两处：

- **批改类型预设为"考试试卷"**（两段式「班级-唯一标识」命名时自动生效）；
- **批改历史按批改类型分流**——本页只显示考试试卷记录，「课时作业批改」页显示课时作业记录；从历史载入时按记录的批改类型自动落到对应页面。

**背后逻辑**：作业与考试的本质差别是"场景与信息（哪次考试、哪个单元）"，而不是"批改算法"——因此两页共用引擎、仅预设不同，判卷行为完全一致（客观题规则判卷、主观题 AI 判定、作文四维评分、待判定兜底、批改即收集）。

### 3. 错题录入——手动补充错题的入口

**功能**：补充录入平时手改的错题并立即得到 AI 分析草稿（批改页判错的题会自动进库，无需在此重复录入）。页顶三步条提示全程：拍照/输入 → AI 分析 → 您确认后计入统计。

**两种模式**（顶部切换）：**📷 拍照切题**（推荐，整页多题一次录入）与**✎ 单题录入**（逐条录入，分析后自动清空本题继续录下一条）。

#### 📷 拍照切题（推荐）

**适合场景**：一张照片里有多道题、多种题型（选择/判断/完形/阅读混排）、甚至跨页——真实批改场景的标准解法。

**操作**：

1. （建议）右上角先选定班级；
2. 左卡上传照片：点击拍照/多选、或拖入图片，**1–10 张**（多页试卷可连拍多张）；缩略图带序号，点 ✕ 可移除；
3. 选任务类型与唯一标识（用过的标识可从下拉选择，自动带出任务类型）→ 点「开始识别切题」（每张约 10–60 秒）；
4. 右侧逐题核对：每题一张卡（勾选框 + 题型下拉 + 可编辑题干/原文 + 作答/正确答案 + 关联学生代号多人逗号分隔）——**识别不准可改，不要的题取消勾选或点"✕ 不要这题"**；
5. 点「✓ 提交所选题 → AI 分析」——一次提交全部，同题多人自动展开；
6. 提交后全部为草稿状态，到「错题确认」页确认后计入统计。

**识别不佳的兜底方案**：让学生自行裁剪单题照片发来，用「✎ 单题录入」逐张上传（题干留空自动识别）。

#### ✎ 单题录入（手动输入）

**界面**：左卡「单题录入」表单——两个带分隔线的分节：**① 题目内容**（顶部紧凑的拍照上传条、题干（必填）、题型、**学生作答与正确答案左右并排对照**、原文输入框选阅读/完形时出现）与**② 关联与上下文**（学生搜索、折叠的任务类型与唯一标识）；右卡展示分析结果。

**操作**：

1. （建议）右上角先选定班级；
2. 填写题干与学生作答，**Ctrl+Enter（Mac 为 ⌘+Enter）快速分析**；
   - **关联学生**：输入代号或姓名实时搜索（如 `92101` / `刘诗涵`），↑↓ 键选择、Enter 确认——名册大时比下拉快得多；留空则不关联（完全不影响分析与班级统计）；
   - **题型选「阅读理解」或「完形填空」时自动出现"原文"输入框**：粘贴完整原文后，AI 分析会结合原文定位证据；
   - **拍照上传**（在①节顶部）：点击或拖入图片，题干留空时自动识别照片文字；也可直接在下方粘贴文本；
   - 任务类型 / 唯一标识折叠在"更多信息"里，**连续录入时自动保留**（选择已有标识会自动带出任务类型）；
3. 点「开始分析」→ 右侧显示 AI 分析草稿：错因类别（36 类之一）+ 题型徽章 + 关联学生徽章（供确认前核对）+ 证据 + AI 把握程度；
4. 分析后表单自动清空题干/作答/学生等本题字段（保留题型/任务类型/唯一标识），表单下方绿色提示"本次已录 N 条，到「错题确认」页确认 →"——适合连续录入整场测验；
5. 分析结果此时是**草稿状态**，需到「错题确认」页确认后才计入统计。

**注意**：上传内容仅为题目文本/图像，学生代号不进入任何模型请求（页面底部有脱敏声明条）。

### 4. 错题确认——您主导的质检关口

**功能**：审校 AI 分析草稿——批改自动收集的错题与手动录入的错题都在这里汇总。**没有教师确认，数据不进任何统计**——这是"教师主导"的第一道关口。

**减负设计（批量采纳）**：待确认视图顶部提供两个批量按钮——**「✓ 一键采纳有把握的（≥80%）」**（推荐，其余留待逐条把关）与「采纳全部」；均有确认弹窗，只作用于当前班级（选定批次时只作用于该批次）的待确认记录，不影响已忽略/已改判数据。

**题型差异化呈现**：每条错题带彩色题型徽章（阅读理解紫色 / 完形填空橙色 / 其余蓝色）；阅读与完形题附"▸ 阅读 / 完形原文（点击展开）"折叠条；超长题干默认收起约 3 行，点击展开全文——避免界面被长文撑爆。

**界面**：错题卡片列表（含题干、错例、AI 分析与证据），顶部过滤：待确认 / 已确认 / 全部 + **「批次」下拉**（全部批次 / 某次作业 / 某次考试——按录入时间倒序，显示日期与条数），选定后列表与批量确认都只作用于该批次。**列表分页展示（每页 50 条）**：底部上/下页按钮 + 拖动滑块快速跳页，替换式渲染（每页只挂当前页卡片），错题几百条也不卡；确认/采纳单条后留在当前页。

**操作**（每张卡片三选一）：

- **✓ 确认**：AI 分析正确，计入统计；
- **✎ 改判**：从 36 类下拉中选择正确类别——改判全程留痕，统计自动以改判为准，并累积"您的改判率"；
- **— 忽略**：录入有误/重复等，该题退出统计。

**背后逻辑**：统计口径在 SQL 层强制 `COALESCE(teacher_override, category_id)`，"改判优先"不是界面承诺而是数据层铁律。

### 5. 错因分析——班级错因的全景与趋势（总览 / 趋势两段）

**功能**：页顶分段「总览 | 趋势」——**总览**回答"这个班现在最需要处理什么"（日常使用频率最高的视图），**趋势**回答"我讲过之后，这类错因真的在减少吗"。两段共用同一套确认口径的数据，一个看现状、一个看变化。

#### 总览段

**界面**：

- 顶部**小结**（确定性规则生成，数字来自真实统计、不编造）：一句话概括——已确认多少条、错因集中在哪、什么在上升、还有什么待确认；无数据时提示先去录入与确认；
- 四张统计卡：错题总数 / 待确认错因 / 已确认（计入统计）/ 涉及学生人数；
- **主要错因排行**（条形图，只统计您确认过的）——班级当前的主要矛盾；
- **周错题量**（柱状图，按录入时间分周，含待确认）——录入节奏与总量走势；
- **预警区**：某类错因比上一周增加超 50% 且人次 ≥3 时自动提示"建议下节课重点关注"；
- 底部：导出当前班级错题明细表格（Excel 可直接打开，仅含代号不含姓名）。

**操作**：总览段「任务类型」下拉可聚焦课时作业或考试试卷，「批次」下拉（总览与趋势共用）可进一步锁定某次作业 / 某次考试——四张统计卡、主要错因、周错题量随之过滤；预警为全期环比（不随任务类型与批次筛选，界面有标注）。

**背后逻辑**：只统计确认过的数据（忽略不计、改判优先）；演示数据为一学年 13 批次（8 次作业 + 5 次考试），可看到主线错因"期中前高发 → 讲评后递减 → 期末见效 → 春季小幅反弹 → 持续下降"的完整叙事。

#### 趋势段

**界面**：

- 两张卡：**您的改判率 / 您改判的题数**（"AI 辅助、您主导"的证据）；
- **错因类别趋势折线图**（前 6 类，纵轴人次，只统计确认过的）：顶部切换**按周 / 按月 / 按半年**三种时间粒度；
- **题型趋势折线图**（前 6 种题型）：哪些题型错得多、是否在下降；
- **需关注学生**（确认错题最多的前 8 人）：代号·姓名 + 次数条形 + 主要错因，点击行可打开个人错题档案（仅供辅导参考，不得下发）。

**操作**：段内切换按周 / 按月 / 按半年（折线图联动）；「批次」下拉与总览段共用，选定后趋势只看该次作业 / 考试；折线上的点悬停可见具体人次。

**背后逻辑**：需要至少 2 个时间段的确认数据才会出图；重点错因曲线应随讲评推进而下降——下降就是教学有效性的直接证据（也是参赛演示中最有说服力的一段）。

### 6. 讲评备课——讲评方案 + 配套练习 + 智能组卷（顶栏二级标签）

**功能**：点击顶栏「讲评备课」后，下方出现三个二级标签「讲评方案 | 配套练习 | 智能组卷」——**讲评方案**一键生成可直接打印带进教室的讲评方案；**配套练习**针对重点错因生成针对性练习；**智能组卷**按错题分布生成综合试卷，形成“讲评 → 练习 / 组卷巩固”闭环。

#### 讲评方案标签

**界面**：顶部「数据范围」选择卡（**全部历史**（默认）/ **按批次**（多选某几次作业或考试，点选成标签）/ **按阶段**（时间范围，含近一月 / 三月 / 一年快捷键））+ 单据头部（数据范围 / 班级 / 班级人数 / 确认错题数 / 记录编号）+ 四个段落：

- **① 本课重点讲（错得最多的前 3 类）**：每类含人次与占比、教学要点（系统内置）、2 条真实典型错例（含学生代号与判断依据）；已审校的配套练习会挂上绿色徽章，没有则显示“去生成→”一键跳到配套练习标签并自动预选该类别；
- **② 本课不讲清单**：错误率 <10% 的类别——明确"不讲"并给个别反馈建议，把课堂时间还给重点；
- **③ 个别辅导名单**：同类错因 ≥4 次的学生（仅代号），附辅导建议——面向个体，不进课堂；
- **④ AI 讲评执行策略**（点「✦ AI 讲评策略」按需生成，约 10–30 秒）：总体策略与 45 分钟时间分配、每类重点错因的**切入话术（引用真实错例）、讲解步骤、板书建议**、不讲清单处理方式、个别辅导组织方式、风险提醒。

**操作**：选班级与任务类型 → 选数据范围（全部历史看全貌；按批次只讲评某次作业 / 考试，可多选如"期中 + 月考"；按阶段限定时间段，如上学期）→「生成讲评方案」（每次进入自动按最新确认数据重新生成，范围变化时自动重算）→ 需要时点「✦ AI 讲评策略」生成第④段（AI 策略与规则数据同范围同源）→「打印」适配 A4 打印版式。底部固定印有三条使用禁令（不得给学生排名比对、不得用于综合素质评价、代号与姓名的对应关系只存在您这台电脑上）。

**背后逻辑**：**规则出数据 + AI 出策略的混合架构**——①–③由确定性算法产出（重点讲门槛 ≥3 人次、不讲 <10%、辅导 ≥4 次，数字全部来自 SQL 统计可追溯）；④由大模型基于上述数据生成讲评执行策略，prompt 硬性约束"数字以给定数据为准、focus_advice 覆盖每个重点错因、不评价学生"；生成后自动留档快照编号（含范围标签，可追溯），AI 策略生成失败不影响①–③正常使用；批次 / 阶段范围在 db 层统一过滤（旧数据经批次兼容映射同样命中），导出与页面同源同口径。

#### 配套练习标签

**功能**：针对讲评方案重点错因生成针对性练习，形成"讲评 → 练习巩固"闭环。

**界面**：左卡生成器（错因类别下拉 36 类 + 题数输入框 1–100 可手输 + 生成按钮，真实模式下有"AI 生成中"进度提示）+ **「错例时间范围」行**（起止日期 + 近一月 / 近三月 / 近一年快捷 + 全部历史；设范围后 AI 参考该阶段班级真实错例出题，范围随练习留档显示在卡片 ⏱ 徽章上）；右侧练习列表，按状态过滤：草稿 / 已通过，**每页 10 套分页展示**（套内默认只显前 3 题，可展开），滑块/按钮翻页。

**操作**：

1. 选类别（从讲评方案标签点“去生成→”跳到本标签并自动预选）与题数（1–100 手动输入，默认 5；题量大时自动分批生成，每批 10 题、批间防重复）→ 生成；
2. 生成的练习为**草稿状态**，逐题审校：题型徽章（单选/填空等）、题干、选项、参考答案、解析、AI 标注；
3. 逐题「通过」→ 全部通过后该套练习标记为已审校，自动挂在讲评方案对应错因下（绿色徽章）。

**背后逻辑**：AI 依据每类错因的典型特征与教学要点生成；阅读理解类错因会生成"短文 + 2-3 题"，短文原文以折叠条呈现；答案缺失的题会被过滤不入库；**未审校的练习绝不会出现在讲评方案上**。

#### 智能组卷标签

**功能**：基于本班已确认错题的分布出一份综合卷——错得多的类别多出、题型混合覆盖（含选择题 / 阅读 / 书面表达），难度与题型偏好可调（留空则自动适配）。

**界面**：顶部提示当前范围（未选班级时建议右上角先选定）；生成表单：卷名（可留空自动命名）、错题来源范围（任务类型筛选）、题量、难度、题型偏好 + **「错题时间范围」行**（起止日期 + 快捷按钮，只统计该阶段内确认的错题，留空 = 全部历史；阶段内没有确认错题时显式提示）；下方试卷列表（草稿 / 已通过，**每页 10 套分页展示**），每套试卷导出支持**学生卷**（无答案，仅限已审校试卷）与**教师版**（含答案解析，审校辅助用）——草稿态学生卷按钮灰显提示，教师版随时可导。

**操作**：

1. 选定班级与范围 → 点「生成」→ AI 按错题分布出卷（标记"AI 生成·待审校"）；
2. 逐题审校、通过——**未审校的试卷不能导出学生卷**（教师版可先打印核对）；
3. 审校通过后导出打印（学生卷 / 教师版）。

**背后逻辑**：组卷范围与讲评方案同源（班级 + 任务类型的已确认错题分布），"错题 → 分析 → 讲评 → 组卷巩固"形成完整闭环；合规边界与练习一致——题目类导出只含题目本身，不含任何学生数据。

### 7. 学生管理——名册、个人错题档案与反标签化设计

**功能**：维护"代号 ↔ 姓名"对应表（增删改）；**点击任一学生可查看其个人错题档案**（含按月错题趋势，仅供您辅导参考），支持单生报告导出与全班打包下载。

**界面**：左卡导入表单 + 三条使用禁令；右卡按班级分组展示全部已录入学生，卡头部有两个导出链接（「⤓ 全班学生报告」每生一个错题档案网页打包 zip；「⤓ 导出综合信息」汇总 CSV，均随右上角班级选择器联动）；学生徽章为"**代号 · 姓名**"格式（如 `92001 · 王雨泽`），每个徽章带 ✎ 编辑（删除也在此，防误触——名册无直接删除按钮）。每个班级标题旁有「✎ 管理」：可给班级改名（该班学生与错题归属自动跟随）或删除。

**操作**：

- **快速新增**：右卡顶部输入代号 + 姓名点"＋添加一人"（临时转来的学生无需改导入文件）；
- **导入**：每行一个「代号,姓名」或「代号,姓名,班级」（中文逗号、空格分隔均可）；未写班级的行自动归入当前选中班级。例：`S01,王一帆`、`S02,李知行,9年级21班`；
- **编辑（✎）**：弹层修改代号/姓名/班级；**改代号时自动级联更新其全部错题记录**，不断链；新代号已被占用会拒绝并提示；
- **删除学生（编辑弹窗底部，防误删）**：名册不设直接删除按钮——点 ✎ 打开编辑弹层，底部"删除该学生…"进入二次确认弹层（红色标题）；**删除学生将同时删除该生全部错题与已上传的批改照片（不可恢复）**；
- **删除班级（班级标题旁「✎ 管理」）**：**连同该班全部数据一并删除**（学生 / 错题 / 配套练习 / 组卷 / 批改记录 / 已上传照片），操作前有二次确认提示——并非"仅空班级可删"；
- **点击学生徽章 → 弹出个人错题档案**：姓名与班级、4 项统计（确认错题 / 待确认 / 涉及错因类别 / 最近错题数）、错因分布条形图（已确认的，最多展示 6 类）、**📈月度趋势**（近 6 个月：每月条形 + 合计 + 当月五大组分布，顶部一句环比提示——只描述数据，按录入时间、已确认口径）、最近 20 条错题（含题型徽章、原文折叠条、作答）；标题行「⇩ 导出报告」下载该生打印友好网页（同四段内容，可另存 PDF）；底部为合规提示。

**背后逻辑**：姓名只在这台电脑上的"学生管理"页与"个人档案弹层"显示，供您面批准备；**档案与导出的报告均只呈现原始错题与计数（含月度趋势），不生成任何评价性结论、不参与排名**。学生代号的聚合用途仅两处：讲评方案③"个别辅导名单"与错题档案统计；删除学生时默认连同其错题与照片一并删除，学生转学/退赛后个人数据不留存。
